## So Momma（モンマ ソウ）

ソフトウェアエンジニアです。「毎日少しずつ成長」をモットーに、日々技術を磨いています。

### スキルセット

#### プログラミング言語
- **Go**: バックエンド開発、API構築
- **Python**: スクリプティング、データ処理
- **JavaScript/TypeScript**: フロントエンド開発

#### フレームワーク・ツール
- **Web**: Hugo, Next.js
- **バージョン管理**: Git
- **コンテナ**: Docker
- **BaaS**: Firebase

### このブログについて

**ChiriTsumomma**（ちりつも）は、「ちりも積もれば山となる」という言葉から名付けました。

このブログでは以下のような内容を発信していきます：

- 📝 **技術メモ**: 開発で学んだこと、詰まったポイントの備忘録
- 📚 **読書感想**: 技術書やその他の本の読書記録
- 💭 **ポエム**: エンジニアとしての日々の気づきや思考

小さな学びを積み重ねて、大きな成長につなげていきたいと思っています。
