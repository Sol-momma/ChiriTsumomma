2025年1月21日の学習記録

So Momma
公開日 オン 2025年1月21日, 更新日 オン 2025年11月22日.

今日学んだこと

Gitコマンド

git diff origin/develop > diff.txt

developブランチとの差分をファイルに出力する方法を学びました。レビューや変更内容の確認に便利です。

スキーマについて

データベースのスキーマ設計について理解を深めました。テーブル構造の設計は、アプリケーションの基盤となる重要な部分ですね。

今日の成果

  • ✅ スキーマについて理解した
  • ✅ 新しくブログを始められた
  • ✅ Hugoの技術選定ができた
  • ✅ Windows風のAltTabアプリケーションを導入できた

小さな積み重ねが大切です。明日も頑張ります！
